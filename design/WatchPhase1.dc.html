Full row set (both platforms, in order): Connection · Phone app version · Watch app version · Protocol · Data age · Session ID · Maneuver ID · Route revision · Updates received · Dropped · Last error · Ping.
Data age and ping are live. Values go amber at > 5 s age or > 500 ms ping, red when disconnected. Tap any row to copy it to the phone's debug log (device-testing aid; removed before release).
Reachable only from Idle: Wear long-press on Idle, Apple scroll past Idle's fold. During a route it's the third pager page so testers can watch counters without leaving guidance.

Page order during a route
Navigation → Scorecard → Diagnostics, left to right (Wear swipe; Apple crown/vertical page). Opening the app, raising the wrist, or tapping the ongoing chip always lands on Navigation regardless of the last page.
Route ends
"Arrived" holds 3 s (haptic: Arrived), then the pager collapses to Idle. If the route is canceled on the phone, "Route ended" holds 3 s instead — no recap in Phase 1.
Explicitly out of scope
No start/stop/cancel, no re-route choice, no "Open on phone". The watch is read-only until Phase 4.
